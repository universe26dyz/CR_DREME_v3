# Cardiorespiratory identity audit before R1

This read-only audit asks whether late non-PC1 and local non-rigid motion explains reproducible acquired-image structure. No R1 training or checkpoint mutation occurs. Respiratory-like, cardiac-like, PC1, non-PC1 and local non-rigid motion are proxies; no ground-truth cardiac phase is inferred.

For each checkpoint, all QC-valid frames are re-encoded using posterior mean. Location-centered global PCA is recomputed with the existing function and both basis and every PC1 score are checked against the hashed latent-stage artifacts. At the SAX anchor, pure PC1 is `mean(anchor μ) + raw_pc1 * global_v1`. Its full crop uses the existing LPS coordinates, validated static spacing and forward deformation. Full versus pure differences are evaluated over the crop, static intensity support and, only when explicitly supplied, a cardiac box. Frame statistics are averaged per region in the summary; the RMS field quantity is the RMS of displacement-vector magnitudes. The pre-existing full-latent visualization is read only and its files are hashed.

Per frame, mean LPS displacement defines translation; subtracting it yields the local non-rigid residual. Jacobian determinants are evaluated without clamping on the same crop grid; frequency summaries use the existing timestamp-aware 0.05–0.6 Hz audit window, which may miss higher-frequency temporal components and is not physiological ground truth. Full-domain field and summary arrays require host memory proportional to crop voxel count, although network evaluation is chunked.

Residuals use deterministic representative locations and time-spaced target frames, full slice pixels, the existing NeSVoR Gaussian PSF, and the same sampled coordinates per target across checkpoints. V1 uses the target's posterior mean; V2 uses previous/next means with simple and timestamp-weighted interpolation, never the target code. V2 is target-withheld within the training set, not held-out generalization. NCC is null for constant images. The explicitly supplied CardiacBox is a coordinate box, not segmentation; its configuration hash is recorded, and the user must ensure it is an admitted box for the subject. Without one, cardiac-box metrics are omitted and recorded unavailable.

Interpretation is deliberately conditional: cardiac-like motion in pure PC1 may indicate mixing; extra motion only in full latent may lie outside PC1. A V1-only gain may reflect target-specific nuisance absorption; gains in both V1 and V2 can support reproducible dynamics but do not prove cardiac identity. The comparison reports individual measures and never chooses an authority checkpoint. The reconstruction-improvement entry uses the stored checkpoint's sampled diagnostic, while the V1/V2 entries use the newly defined matched cohort.
