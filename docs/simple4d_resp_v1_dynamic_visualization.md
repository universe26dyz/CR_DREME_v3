# SIMPLE-4D dynamic anatomy visualization

This read-only tool extends the existing `04_dvf` and `01_latent` outputs. It checks stage output hashes, checkpoint identity, static and dynamic input provenance, and the selected NIfTI geometry and sidecars. The selected-state views use the existing low/mid/high volumes directly; the ping-pong GIF displays selected real PC1-percentile observations. Low/high and the sign of PC1 have no fixed inhale/exhale meaning.

For the temporal GIF, the `selected_states.csv` SAX anchor identifies a single location. Each acquired observation is sorted by timestamp and passed through the same checkpoint's `encode_observation(sample=False)` to obtain the full posterior mean, rather than reconstructing a code from PC scores. On the unchanged crop grid, external LPS observation points pass through forward deformation to the frozen canonical INR. A volume is rendered in bounded chunks, three fixed central planes are saved, and the volume is released before the next observation. The same slice indices, field of view and [0,1] display window are used throughout. The GIF is a qualitative respiratory-identity visualization, not evidence by itself of physiological correctness.

The default stores frame PNGs and GIFs, not a sequence of 3D volumes. `--save-4d-volume` explicitly enables a potentially very large 4D NIfTI and a timestamp sidecar; irregular acquisition timestamps in the sidecar are authoritative. GIF timing is fixed by `--gif-frame-ms` and does not encode irregular intervals. The selected-state ping-pong uses at least 300 ms per image. Outputs are written only under `04_dvf/step_<STEP>/dynamic_visualization/`; pre-existing output requires `--overwrite`.
